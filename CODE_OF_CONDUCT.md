# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies; this page is a summary and names the contact.

## In short

- Be respectful and constructive. Criticise shapes, code and ideas, not people.
- Assume good faith; type and rendering are subjective and platform-dependent, and reports that "it looks
  wrong" are welcome even when they turn out to be configuration.
- No harassment, insults, discriminatory language or imagery, sexualised attention, or publishing of
  anyone's private information.
- This applies in issues, pull requests, discussions and any other project space, and when representing
  the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@solomonabraham](https://github.com/solomonabraham),
through the contact options on that profile. Content on GitHub itself can also be reported to GitHub with the
*Report content* link next to every comment. Reports are handled confidentially.

## Enforcement

Maintainers may edit or remove contributions that violate this code, and may warn, temporarily block or
permanently ban contributors, following the enforcement guidelines of the Contributor Covenant.
