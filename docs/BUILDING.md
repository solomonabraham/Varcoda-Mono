# Building Varcoda Mono

The fonts are generated by a Python program. No font editor is needed, and nothing in `fonts/` is edited by hand.

## Requirements

- Python 3.10 or later (developed with 3.13 on Windows 11; CI builds with 3.13 on Ubuntu)
- The pinned packages in `requirements.txt`:

| Package | Needed for | Without it |
| --- | --- | --- |
| fontTools, ufoLib2, ufo2ft, skia-pathops | everything | no build |
| ttfautohint-py | hinted TTF | TTFs are built unhinted |
| afdko (`otfautohint`) | hinted OTF | OTFs are built unhinted |
| brotli | WOFF2 | web fonts are skipped |
| uharfbuzz | the byte layout of the GSUB table | equivalent fonts that are not byte-identical to the released files |

```sh
python -m venv .venv
. .venv/bin/activate            # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt afdko==5.0.1
```

On Windows, activate the environment before building: `otfautohint` is found on `PATH`, and without it the OTFs
are built unhinted without an error.

## Build

```sh
python scripts/build-fonts.py                 # all ten styles: UFO, TTF, OTF, WOFF2 (under a minute)
python scripts/build-fonts.py -w Regular Italic --no-otf --no-woff2     # fast loop while designing
python scripts/build-fonts.py --from-ufo      # compile sources/*.ufo as they are (after hand edits)
python scripts/build-fonts.py --root /tmp/out # build somewhere else
```

Style names for `-w`: `Light Regular Medium SemiBold Bold LightItalic Italic MediumItalic SemiBoldItalic BoldItalic`.

| Output | Location |
| --- | --- |
| UFO sources | `sources/VarcodaMono-<Style>.ufo` |
| TrueType, hinted | `fonts/ttf/VarcodaMono-<Style>.ttf` |
| OpenType/CFF, hinted | `fonts/otf/VarcodaMono-<Style>.otf` |
| Web fonts and stylesheet | `fonts/webfonts/VarcodaMono-<Style>.woff2`, `varcoda-mono.css` |

## Reproducible builds

With the pinned packages, two builds of the same sources are byte-identical: on one machine (a test checks this),
and between Windows 11 and Ubuntu, both x86-64. The timestamp inside the fonts is fixed; set `SOURCE_DATE_EPOCH`
to change it. The *Build* workflow rebuilds every font on each push and fails when a committed file differs.

One package deserves its pin more than it seems to. fontTools packs the GSUB table with HarfBuzz when `uharfbuzz`
is installed and with its own packer when it is not. Both results are correct and shape identically, but the
bytes differ, so a build without `uharfbuzz` does not reproduce the released files. macOS and ARM machines have
not been compared.

## Where the design lives

| File | Content |
| --- | --- |
| `scripts/fontsrc/params.py` | the grid, the weights and their pens, the italic angle |
| `scripts/fontsrc/geom.py`, `kit.py` | geometry: pens, strokes, boolean operations, shared parts (stems, arches, bowls, the blade cut) |
| `scripts/fontsrc/glyphs_*.py` | one function per glyph |
| `scripts/fontsrc/glyphs_liga.py` | ligatures, alternates, generated feature code |
| `scripts/fontsrc/glyphs_italic.py` | the written italic lowercase: exit strokes, branching arches, returning bowls |
| `scripts/fontsrc/italic.py` | the slant, and which glyphs stay upright |
| `scripts/fontsrc/build.py` | names, metrics, tables, compilation, hinting |

Change a number, rebuild, and all ten styles follow. The UFOs in `sources/` are regenerated on each build and are
complete, ordinary sources: they open in Glyphs, FontForge, RoboFont or FontLab.

The version (`VERSION_MINOR`, `RELEASE`), the copyright line and the project address written into the fonts (`URL`)
are constants at the top of `build.py`. `python scripts/rename-family.py "New Name"` renames the family everywhere.

## Images and reports

```sh
python scripts/make-assets.py [--refs DIR]    # assets/*.png, logo.svg, banner.svg
python scripts/make-specimens.py              # specimens/specimen.png, code-samples.png
python scripts/make-regression.py [--refs DIR]# tests/visual-regression/
python tests/rendering-tests/make_page.py     # tests/rendering-tests/index.html
python tests/font-validation/validate.py      # tests/font-validation/REPORT.md (fontbakery, ufolint)
```

These need `pip install -r requirements-dev.txt`. `--refs DIR` points to reference fonts for the comparison
images (`COMPARISON.md`). The logo and banner PNGs are rasterised from their SVGs by headless Chrome or Chromium
(`google-chrome` or `chromium` on `PATH`); without one they are skipped.

## Release archives

```sh
python scripts/make-nerd-fonts.py    # optional, needs Docker: releases/VarcodaMonoNerdFont-<version>.zip
python scripts/make-release.py       # releases/VarcodaMono-<version>.zip, -web.zip, SHA256SUMS
```

`releases/` is not committed; the archives are attached to GitHub releases. The steps of a release are in
[RELEASING.md](RELEASING.md).
